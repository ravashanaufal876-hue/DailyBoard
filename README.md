# 🌟 DailyBoard

DailyBoard adalah aplikasi manajemen harian berbasis web untuk mencatat tugas, catatan cepat, serta memantau cuaca dan kutipan harian secara real-time

## 🚀 Fitur Utama
- Daftar Tugas (Todo List): Tambah, hapus, edit, tandai selesai, filter status, dan fitur Drag & Drop prioritas tugas
- Pencarian Real-Time: Mencari tugas secara instan dengan fitur Debounce agar performa tetap ringan
- Catatan Cepat: Membuat dan mengelola catatan harian dengan mudah
- Widget Cuaca & Kutipan: Memuat informasi cuaca terkini berdasarkan kota dan kutipan bijak dari API publik menggunakan Promise.all
- Dark Mode: Fitur tema gelap/terang yang otomatis tersimpan di localStorage
- Modul Terpisah (ES Modules): Struktur kode rapi yang dipecah menjadi beberapa file (tugas.js, catatan.js, storage.js, api.js)

## 🛠️ Cara Pakai
1. Buka link web yang sudah di-deploy
2. Ketik tugas di kolom "Masukkan Tugas..." lalu klik tombol Tambah
3. Gunakan kolom pencarian untuk mencari tugas dengan cepat
4. Klik tombol Dark Mode di pojok kanan atas untuk mengubah tampilan menjadi gelap
